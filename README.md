# YesLab 新成员任务
### 环境信息
- Ubuntu 版本：20.04.6 LTS
- ROS 版本：Noetic
- 虚拟机软件：VirtualBox 7.2.18
### 一、Ubuntu 与 ROS 环境搭建安装过程与遇到的问题
#### 1. 虚拟机软件选择
b站简单了解后，获取VMware安装包进行安装，并在VMware中导入Ubuntu20.04.6镜像，完成虚拟机配置。

#### 2. Ubuntu系统安装
在VirtualBox中导入Ubuntu20.04.6镜像，完成虚拟机配置。
**遇到问题**：安装界面底部确认按钮被窗口遮挡，无法点击。
解决办法：按住 `Alt` +鼠标左键拖动窗口，把窗口向上移动，露出被遮挡的按钮，继续完成系统安装。

#### 3. ROS Noetic安装
使用小鱼一键ROS安装脚本，一键完成ROS Noetic安装。脚本自动把ROS环境变量写入`.bashrc`，实现终端打开自动加载ROS环境。
**遇到问题**：apt下载源访问失败，出现404报错与“CMD Result:code:2”红字提醒。
解决办法：一键脚本内置国内镜像源，自动规避国外源访问异常。

#### 4. ROS环境验证
新开终端执行 `roscore`，成功启动ROS核心；
运行 `rosrun turtlesim turtlesim_node`，调出小乌龟窗口，键盘控制小乌龟移动，验证ROS功能正常。
